**Focus**: Sorting, Greedy Algorithms, Graph Traversal
- **Week 1: Sorting & Searching**
  - Study: Bubble, Selection, Insertion, Merge, Quick Sort, Binary Search
  - Practice: Implement sorts, solve [LeetCode Problems](https://leetcode.com/tag/sorting/) (e.g., 912, 34, 153).
- **Week 2: Greedy Algorithms**
  - Study: Activity Selection, Fractional Knapsack, Huffman Coding
  - Practice: [Greedy Problems](https://leetcode.com/tag/greedy/) (e.g., 455, 435, 56).
- **Week 3: Basic Graph Algorithms**
  - Study: BFS, DFS, Topological Sort (Kahn’s, DFS-based)
  - Practice: [Graph Traversal Problems](https://leetcode.com/tag/graph/) (e.g., 207, 210, 200).
- **Week 4: Consolidation & Contests**
  - Solve 20+ problems from Codeforces Div 2/3 rounds (A-C).
